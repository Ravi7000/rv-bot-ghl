# RV Bot GHL - Standalone Version

A complete standalone RV maintenance chatbot for GoHighLevel integration.

## Features
- ✅ Zero WordPress dependency
- ✅ Node.js backend with JWT authentication
- ✅ React frontend with streaming chat
- ✅ PostgreSQL database (Supabase)
- ✅ OpenAI & Gemini AI providers
- ✅ GHL webhook integration
- ✅ Subscription management

## Quick Deploy
1. Deploy backend to Vercel
2. Deploy frontend to Vercel
3. Setup Supabase database
4. Configure GHL integration
